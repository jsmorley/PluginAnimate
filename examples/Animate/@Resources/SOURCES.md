# Animated WebP example

`DancingBanana.webp` is an unchanged copy of the lossless animated WebP sample
linked from [Google's WebP FAQ](https://developers.google.com/speed/webp/faq#why_should_i_use_animated_webp).

- Source: https://storage.googleapis.com/downloads.webmproject.org/webp/images/dancing_banana2.lossless.webp
- Publisher: Google, WebP documentation.
- License: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/),
  under the FAQ's content license notice.
- Downloaded November 1, 2026; renamed only. 8 frames, 4,764 bytes.

libwebp decoder licensing is separate; see `third_party/libwebp-1.6.0/COPYING`
and `PATENTS` in the plugin repository.
